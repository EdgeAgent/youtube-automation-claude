# Channel Optimization Checklist

The channel-level companion to the packaging playbook. Run it when a
channel launches, then monthly. **Audit first, change only what
actually falls short, and read back after saving to confirm the
change stuck.**

## 1. Channel description

The description is search text and a sales pitch in one. Formula:

1. **Line 1 — what this channel posts**, with the niche's main
   keywords in it naturally. ("Daily [niche] clips — the fails, the
   funniest moments, and the secrets nobody else finds.")
2. **Line 2 — cadence.** How often you upload, stated plainly.
3. **Line 3 — the subscribe call.** One line, direct.
4. **Then**: what makes the channel different, the source/credit line
   for your footage, and the not-affiliated disclaimer if you work
   with third-party material.
5. Contact/business line last, if you want one.

Check: could a stranger tell in five seconds what they get, how
often, and why subscribe? If not, rewrite.

## 2. Channel keywords

Set the channel keywords (Studio → Settings → Channel → Basic info)
to your niche's **canonical tag set** — the same list your per-video
tags fill from. One vocabulary, everywhere: channel keywords, video
tags, description language, titles. Build the set from the top
videos in your niche, not from guesses, and refresh it when your
outlier data moves.

## 3. Per-video audit

For every video on the channel, check against the pack standard:

| Field | Standard |
|---|---|
| Title | Curiosity up front, ending withheld, niche search words when honest |
| Description line 1 | Hook line — not the title repeated |
| Description line 2 | Subscribe line present |
| Description body | Credit to source + disclaimer present |
| Secret/how-to videos | Exact steps present in the description |
| Tags | ~490–500 chars, video-specific first, canonical fill, generics trimmed from the end |
| Thumbnail | Real frame, bold short text, legible at 320px wide |
| Playlist | Set, and the right one |
| Visibility | Public, correct audience setting |

Fix only what fails. Churning fields that already pass wastes the
read-back time and can only introduce errors.

## 4. Playlists

- One playlist per format (Shorts, compilations/longs, series).
- A new video joins its playlist before publish, not after.
- Playlist titles carry niche keywords too — they're search text.

## 5. The monthly review

1. Pull the month's top 3 videos by **APV** (not views).
2. Write each one's pattern in one line.
3. Compare against your niche config: do the winning types and the
   canonical tags still match what your own data says wins?
4. Update the config if the data moved. The config is a living
   document; the QC bar (`min_ship_score`) is not — don't lower it
   to make a weak month feel productive.
